- [`synthetic_benchmark_dataset.csv`](https://github.com/amith2427/Green-Catalyst-Screening/blob/main/synthetic_benchmark_dataset.csv): Seed 42 reference dataset (5,000 synthetic reactions; 13 columns). Updated on GitHub from the files supplied on 4 November 2026.
- [`20_seed_metrics_log.csv`](https://github.com/amith2427/Green-Catalyst-Screening/blob/main/20_seed_metrics_log.csv): model metrics and TreeSHAP log (seeds 42–61; 20 rows; 34 columns). Updated on GitHub from the files supplied on 4 November 2026.
- [`supplementary_experiments_log.csv`](https://github.com/amith2427/Green-Catalyst-Screening/blob/main/supplementary_experiments_log.csv): positive-control substrate-effect runs (40 rows across σsub = 0, 4, 8, 12 for seeds 42–51) and seven Seed 42 learning-curve rows. Added to GitHub from the supplied CSV on 4 November 2026.
